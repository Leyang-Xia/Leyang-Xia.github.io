# Markdown 写作指南

文章保存在 `personal-site/content/posts/`，元数据格式见仓库 README。正文支持 CommonMark 和表格、脚注、删除线、任务列表扩展；[综合示例](../personal-site/tests/fixtures/markdown/showcase.md)可作为排版参考。

## 标题与段落

文章标题填在 front matter 的 `title` 中，正文使用 `##`、`###` 到 `######`。段落之间留空行，段内普通换行显示为空格；行尾两个空格或反斜杠表示强制换行。

支持 `**加粗**`、`*斜体*`、`~~删除线~~`、反引号行内代码，并可嵌套，例如 `**重点里的 *强调* 和 [资料](https://example.com)**`。原始 HTML 显示为文字。

## 列表与引用

```markdown
- 第一项
  - 嵌套项

  第一项的第二段，缩进至外层列表的正文位置。

- 第二项

1. 步骤一
2. 步骤二

- [x] 已完成
- [ ] 待完成

> 引用段落。
>
> 引用的第二段，也能放列表。
```

任务列表显示只读勾选状态，修改 Markdown 中的 `[ ]` / `[x]` 后重新构建。

## 表格与分隔线

```markdown
| 方法 | 结果 |
| :--- | ---: |
| 固定输入 | 12 |
| 对照方案 | 15 |

---
```

冒号指定对齐方向。单元格中的竖线写成 `\|`；表格单元格不支持多段块内容。手机上的宽表格在表格区域内横向滚动，也可用键盘聚焦该区域。

## 链接与图片

```markdown
[带括号的地址](https://example.com/audio_(notes))
[含空格的地址](<https://example.com/audio notes> "可选标题")
[引用式链接][source]
<https://example.com/docs>

![对照波形](/assets/waveform.svg "可选图片标题")
![引用式图片][figure]

[source]: https://example.com/docs "资料"
[figure]: /assets/waveform.svg
```

本地图片先放到 `personal-site/dist/assets/`，建议使用站点根目录路径 `/assets/waveform.svg`。构建会同步资源到根目录；与文章 URL 相对的路径则按最终 `writing/<slug>/` 页面解析，而非按 Markdown 文件位置解析。URL 中的空格可用尖括号包围或写成 `%20`。本地和外部图片是否可访问需在 HTTP 预览中检查，构建不会请求外部图片。

替代文字描述图片内容，它同时用于辅助阅读和站内搜索。图片自适应正文宽度，不要在替代文字中堆放长网址。

链接可使用 HTTP(S)、mailto、相对路径和页内锚点；图片只支持 HTTP(S) 或相对路径。原始 HTML、嵌入 iframe、data URI、脚本协议、协议相对地址（`//...`）和含账户信息的 URL 不启用。页内链接需指向实际存在的 ID；正文标题目前不自动生成锚点，脚注锚点由解析器生成。

## 脚注

```markdown
这是需要补充说明的结论。[^method]

[^method]: 解释实验条件。

    脚注中的第二段缩进四个空格，可继续使用 **强调** 或链接。
```

脚注汇总到文章末尾，编号与返回链接自动生成，同一脚注可以多次引用。脚注正文参与搜索，编号和返回符号不进入索引。

## 代码

````markdown
```python
# 缩进和换行会保留。
print("<audio>")
```
````

也可以使用 `~~~` 围栏或四个空格的缩进代码。当前显示等宽文本，无需额外脚本，语言名保留但不进行语法高亮。

未定义的引用链接显示为文字，未闭合的代码围栏延续到文末；这是 Markdown 的容错行为，发布前仍应查看预览。公式渲染和 Mermaid 尚未启用。
