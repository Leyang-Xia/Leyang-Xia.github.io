# 留言系统上线与审核

当前代码只提供评论前端。未配置 `TWIKOO_ENV_ID` 时，正式站点显示“评论暂不可用”；预览站始终不加载正式评论。**在完成以下检查前，不应宣布留言功能已经开放。**

## 部署

1. 按 [Twikoo 官方 Netlify 部署说明](https://twikoo.js.org/backend.html#netlify-%E9%83%A8%E7%BD%B2)建立 MongoDB Atlas 数据库，将连接串仅设置为 Netlify 环境变量 `MONGODB_URI`。不要把连接串写入此仓库、终端命令历史或生成的 HTML。
2. 将 `twikoojs/twikoo-netlify` 仓库导入 Netlify，等待函数健康页显示“Twikoo 云函数运行正常”。公开地址的格式为 `https://<你的站点>.netlify.app/.netlify/functions/twikoo`。前端固定使用 `twikoo@2.0.9`，后端版本应与之匹配。
3. 在评论管理面板设置管理员密码。进入配置管理，启用人工审核，并把昵称设为必填、邮箱设为选填。管理员密码由站长本人设置，不交给网站构建脚本。
4. 构建并发布：在本机设置公开地址 `TWIKOO_ENV_ID`，运行 `python3 personal-site/build.py`，检查生成文件后提交并推送 `main`。`TWIKOO_ENV_ID` 只是公开服务 URL；数据库连接串不可注入前端。
